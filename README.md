# 猫思之 · CatThinking

**能回到原文的学习工作台。理清知识，测出疑问，回到原文。**

猫思之面向课程学习、考试复习与实验理论整理：把资料变成有层次、可编辑的知识结构，先自测，再回看需要复习的题目和原文。摘要、大纲、思维导图、测验与知识整理共用原文依据；用户可以核对、调整自己的理解。

文档编辑与本地保存可以独立使用。需要 AI 时，在应用里填入自己的 API 密钥和模型即可连接；生成会发送所选原文给服务商，使用服务商额度。

## 按学习目标使用

默认首页是面向高校课程与复习的暖纸色学习工作台。「开始今日学习」来自已保存的课程、知识点与复习安排；没有数据时展示零与导入入口。课程、练习、知识、备考、记录和备份在页面内打开。侧栏「思维导图」进入 `#mindmap` 工具，顶部「学习首页」返回；浏览器前进和后退也可切换这两个入口。

1. 导入课程资料，在「AI 分析」选择「整理要点」，或选择「理解结构」。想在同次分析中看结构并自测，选择「理解结构」后再勾选「测验」，确认内容后点击生成。
2. 查看引用、调整知识层级；生成的导图可另存为独立文档继续编辑。
3. 在本次测验中先作答，再提交查看答案；只需要练习时，也可在新任务开始前选择「自测复习」。
4. 查看「本次待复习内容」，回到未答、与参考答案不一致的题目或简答自评要点，再打开原文复核。

目标按钮只调整勾选，点击生成才调用模型；可以自行选择其他内容。当前已有任务暂不能追加新的内容种类，因此请在生成前选好。复习清单从当前作答生成，查看、定位、作答和自评不增加 AI 生成调用。未保存到课程的本次清单不提供长期历史；持续练习与排期使用下面的课程入口。客观参考答案也需要结合原文检查。

## 持续使用课程资料

1. 从首页 **我的课程** 创建课程，或导入课程资料；在资料页把已有文档加入课程。导图工具内的 **今日学习** 仍能打开课程工作台。
2. 在 AI 分析结果里选择 **保存为学习资料**，保存校验后的原文与结果快照。之后可以在课程工作台查知识、做已有题、查看历次提交和回查归档原文；原分析任务删除或到期后，完整归档仍可读取。
3. 复习安排支持手动日期和可关闭的自动规则，今日页面会按课程时间与题数上限提供建议。它记录练习表现和自评，不代表知识掌握率；题目有疑问时可暂停。
4. 在课程的备份页导出 **.mszcourse**，可设置至少 8 字符的密码。课程包包含现存课程文档、附件、归档原文、作答历史与复习安排；恢复前先检查，确认后恢复为新课程。它不包含 API 密钥、可执行后台任务或后端完整调用账本。

课程包校验上限为文件 192 MB、内容 128 MB、附件总量 64 MB；超限会停止导出或恢复，不静默丢弃大附件。未加入课程的文档需要另行备份。课程数据仍按浏览器与应用网址保存，尚无云同步。

## 在当前电脑开始使用

当前工作区的应用依赖和本机 PostgreSQL 已准备好，不需要购买云数据库。

启动时会自动避开其他程序正在使用的端口，并打开实际应用地址；不会关闭其他项目。若浏览器没有自动打开，请使用启动窗口里显示的网址。一个数据库只允许一个个人后台管理连接，重复启动时应先在原启动窗口正常停止应用。

1. 双击此文件夹里的 **[启动猫思之.cmd](./启动猫思之.cmd)**。保留打开的启动窗口，浏览器会打开应用。
2. 点击 **AI 设置**，选择服务商，填写 API 密钥，选择模型。也可以刷新可用模型，或手动输入模型名称。
3. 点击 **保存并连接**。服务商的地址和兼容方式会自动填好；自定义服务另需填写 API 地址，可以直接粘贴完整接口地址。
4. 导入原文，在 AI 面板选择需要的内容并开始生成。支持摘要、大纲、思维导图、练习题和知识卡。

顶部 **使用教程** 和 `Ctrl+K` 命令面板里的 **打开最新版使用教程** 都能查看完整教程。升级应用不会覆盖你的旧教程或手写笔记；点击入口时，只会复用完全未修改的最新版教程，否则另建一篇。

### 双击启动不了

在 Windows 的 PowerShell 或终端执行：

```powershell
Set-Location -LiteralPath '项目所在目录\cat-thinking'
npm.cmd run start:local
```

把第一行替换成自己实际的项目目录。中文目录可以直接使用；`npm.cmd` 可以避开 PowerShell 对 `npm.ps1` 的执行限制，无需修改全局脚本策略。启动失败时保留终端最后的报错文字，不要附带密钥、完整原文或模型原始响应。

也可以双击 **[诊断启动.cmd](./诊断启动.cmd)**，检查 Node.js 版本、应用文件与依赖。诊断不会安装文件、连接数据库、上传原文或调用 AI。若提示依赖不完整，按提示手动执行 `npm.cmd ci` 后重试；若提示 Node.js 版本不适合，建议安装 Node.js 24，并重新打开终端。

启动成功后请使用窗口中显示的网址，保留启动窗口。不要重复打开多个启动窗口；退出时按 **Ctrl+C**。若端口变化，浏览器的文档库也会随网址变化，因为本地浏览器数据按网址分别保存；尽量保持同一浏览器与应用网址。

预设包括 OpenAI、DeepSeek、通义千问、Kimi、GLM、硅基流动、Google Gemini 和本机 Ollama。名单依据官方文档维护，核验日期为 2026-10-12；模型能否使用取决于你的账号权限、地区和余额，应用同时保留手工添加入口。使用 Ollama 时，需要先在本机运行它并下载模型，可以不填 API 密钥。

自定义入口支持服务商明确提供的 OpenAI 兼容地址。Claude 的 Anthropic 原生地址目前不能直接使用；只有确实提供兼容接口的服务才能走自定义入口。

保存与连接检查只读取模型列表，不发送生成请求。**第一次点击生成才会调用你的模型，并使用服务商额度。** 个别服务商不提供模型列表时，可以手填模型，再明确连接；实际生成能力会在第一次任务中检查。

## 从原文到学习内容

1. 打开文档库，点击 **从文档生成**，导入 TXT、Markdown、DOCX 或 PDF。先检查预览，再点击 **创建可编辑导图**。这里先创建本地结构初稿；需要 AI 整理知识层级与联系时，继续执行下面的 AI 分析步骤。扫描版 PDF 需要先转换成可选择的文字。
2. 点击顶部 **AI 分析**，勾选来源。范围留空使用全文；也可填写 **起始** 和 **结束** 字符，起始从 `0` 计数，结束位置不包含在选区内。第一次建议用一段 1–2 千字符的公开文本。
3. 勾选需要的内容，再点击生成。每次所选原文总量目前最多 100,000 字符；思维导图会同时生成所需大纲，测验题数可以调整。只有选中的原文范围会发送给你连接的服务商。
4. 完成后先核对结果旁的引用，再使用内容。AI 结果可能出错，涉及重要结论时应回到原文确认。

| 内容 | 使用方法 |
| --- | --- |
| 摘要 | 阅读主旨、要点、需要澄清的地方，点击引用核对原文 |
| 大纲 | 按上级主题和子知识逐层查看内容结构 |
| 思维导图 | 先预览层级与关系，再点击 **创建独立导图**、**打开生成导图**；生成独立文档，不覆盖原文文档 |
| 测验 | 先作答，再提交查看答案；客观题显示正确数量，简答题按评分标准自评 |
| 知识整理 | 查看前置知识、应用、类比、对比与拓展，区分有原文依据的内容和推断 |

独立导图可以继续修改父子层级、备注和关系线。重复创建同一份结果会找回原导图，保留手动修改。测验作答保存在当前浏览器，可以重新作答；换浏览器或清理浏览器数据后不会自动迁移。

提交测验后，「本次待复习内容」区分与参考答案不一致、未答、简答待自评和自评未完成的题目，可回看题目与原文。客观题参考答案也需要结合原文核对；简答全部勾选只表示完成自评。重新作答会替换当前面板记录；已保存到课程的分析还会保留各次提交历史。

### 遇到分析失败

先看失败说明和已知用量，再决定下一步。**失败也可能已产生服务商费用**；生成过程中的格式修复也会计入用量，应用不把未知金额显示为免费。

- **恢复查看**用于读取已有任务和结果，刷新页面也不会重新生成。
- 模型结果不符合要求时，先尝试较小的原文范围。只有面板明确提供重试入口时才进行相应重试；无法确认结果的付费调用不会自动重发。
- 首次生成和最多一次结构修复分别使用完整的单次输出额度，二者都计入任务总 token、调用次数与用量。修复仍可能失败，已失败的旧任务不会因升级自动重跑。
- 如果需要重新分析，先保留有用结果，再使用 **删除分析内容**，随后明确创建新任务。重新生成可能再次产生费用。
- **删除分析内容**会删除该任务的后端原文副本、证据和结果，以及当前浏览器的分析关联；导入文档仍保留。已经创建的独立导图需要在文档库单独管理。

## 暂停、切换和忘记连接

- **暂停新分析**会停止调度并取消尚未完成的任务，已经生成的结果和文档仍保留。
- 修改连接或模型时，旧任务先停止；新任务使用新的配置。应用不会用新模型偷偷接着执行旧任务。
- **删除连接与密钥**会擦除已保存的密钥，包括旧配置里的密钥。为避免重复调用、核对用量和恢复任务，任务身份与调用记录仍保留；这些记录不包含 API 密钥。
- 结束使用时，在启动窗口按 **Ctrl+C** 正常停止应用，再关闭窗口。文档和已保存的连接仍保留；下次启动会恢复已启用的连接和允许恢复的任务。无法确认是否已经付费的调用不会自动重发。

API 密钥保存在本机后端的加密存储中，不写入浏览器的本地存储，也不会通过设置状态回传。请在应用中填写密钥，不要把密钥贴到聊天、截图或代码仓库。

应用默认限制每次输出、每个任务的总 token 和调用次数；没有可靠的服务商价格时不会把金额显示成免费。实际费用以服务商账单为准。

## 文档保存与备份

编辑文档自动保存在当前浏览器。更换浏览器、应用网址或电脑，以及清理浏览器数据，都可能让这份文档库不可见；不要把浏览器保存当成长期备份。

- 顶部 **导出 → JSON（完整数据）** 备份当前文档，包含编辑内容、引用原文和不超过 2 MB 的图片或附件。较大的附件要另外保留原文件。
- Chrome / Edge 可以通过 **文件 → 另存为 .msz** 保存可编辑文档，再用 **打开 .msz 文件**继续编辑；大附件同样需要单独保留。不支持直接文件访问的浏览器使用 **导入导图** 恢复 JSON 备份。
- SVG、PNG、PDF 用于展示，不适合作为完整可编辑备份。
- JSON 与 .msz 不包含 API 密钥、服务端 AI 任务记录或测验作答。
- AI 后端数据库另用 `npm.cmd run db:backup` 备份。数据库备份和受保护的加密配置要配套保管，勿公开上传；当前备份仍在同一块磁盘，无法防止硬盘损坏，也不是跨机一键恢复功能。

## 换到一台新电脑

当前 CMD 启动文件是开发工作区的启动入口。另有包含 Node.js、后端依赖与 PostgreSQL 的离线安装包原型，见 [安装包说明](./scripts/desktop/README.md)；干净 Windows 电脑与跨盘恢复验收尚未完成。使用开发工作区时，新电脑需要先准备：

1. 安装 Node.js 24.13.1 或更新的 24 系列版本，与当前 AI 后台的运行要求一致。
2. 在本项目文件夹执行 `npm.cmd ci`，安装应用依赖。
3. 双击 `启动猫思之.cmd`。Windows 启动入口会按需下载并准备本机 PostgreSQL、初始化专用数据库，首次准备需要网络和等待时间，不需要手工填写数据库配置。

启动脚本会按所在文件夹定位项目，不要求固定盘符或中文目录名称。现在的本机数据库安装与启动脚本面向 Windows；其他系统的安装入口还需单独准备。

本项目文件夹是 CatThinking 的前端和 AI 后端工作区。父目录中的旧 DocMind / Python 项目仍保留，使用这里的启动文件即可。

## 后续开发

个人使用入口允许在本机明确保存并启用自己的连接，不需要处理部署签名或 CI 配置。面向公众的生产部署仍保留严格发布检查，不能通过个人设置绕过。

常用命令：

| 命令 | 用途 |
| --- | --- |
| `npm run start:local` | 启动本机数据库、AI 后端和应用 |
| `node scripts/startup-preflight.mjs` | 只检查启动文件、Node.js 与依赖，不调用 AI |
| `npm run db:install` / `npm run db:setup` | 开发时手动准备或初始化本机数据库 |
| `npm run verify:personal:local` | 检查本机个人入口与设置通路 |
| `npm run check:ci` | 类型、代码规范、测试、覆盖率与构建检查 |
| `npm run db:test` | 专用测试数据库中的恢复与个人连接测试 |
| `npm run e2e` | 普通浏览器流程验证 |
| `npm run e2e:personal:local` | 本机假模型的个人连接和完整生成流程验证 |

产品定位、后续功能与开发边界见 [产品方向](./docs/PRODUCT_DIRECTION.md)。技术说明见 [API 与模型兼容说明](./docs/PROVIDER_COMPATIBILITY.md) 和 [AI 后端说明](./services/analysis-service/README.md)。
