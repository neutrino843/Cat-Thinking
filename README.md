# 猫思之 · CatThinking

<img src="./public/images/isis-cat.jpg" alt="学习伙伴伊希斯" width="96" />

**从自己的资料开始，做一道题，把不懂的地方学明白。**

猫思之是一款以课程资料为起点的本地学习应用。导入讲义、课件或笔记后，可以先完成第一道题，需要帮助时回看相关段落，再继续阅读、整理理解和安排复习。小猫「伊希斯」在当前任务旁提供操作引导。

项目目前处于持续开发阶段。资料导入、本地入门练习、已有课程学习和导图编辑可以独立运行；生成更多学习内容需要另外启动 AI 后台并配置模型。

## 目前可以做什么

| 功能 | 当前实现 |
| --- | --- |
| 导入自己的资料 | 支持 TXT、Markdown、DOCX、PPTX 和文字型 PDF；先预览，再保存到课程并创建可编辑导图 |
| 完成第一题 | 根据导入原文，用本地规则生成一道填空入门题，无需先连接 AI |
| 集中学习 | 先显示当前题目，相关段落按需展开；完整原文在独立阅读场景中正常滚动，返回后保留原题和输入 |
| 持续学习与补学 | 使用已保存的知识点和题目，继续练习、回忆、个人解释，或回到原文修正理解；支持暂停与继续 |
| 安排复习 | 根据作答与自评提供日期建议，也可手动安排；首页按当天时间和题量推荐下一步 |
| 伊希斯陪伴 | 短气泡、操作选项和预设问答；可以选择轻陪伴、仅在呼唤时或首次详细引导 |
| 学习记录与纪念 | 查看历次提交、练习与应用记录；六项学习纪念根据实际保存的记录计算 |
| 课程与工具 | 管理课程、知识结构、备考和应用任务；编辑思维导图、大纲及甘特图 |
| AI 内容整理 | 配置模型后生成摘要、大纲、导图、练习题与知识整理，结果可以核对引用并保存到课程 |
| 本地备份 | 导出课程包，恢复前预览；文档与导图也可以单独导出 |

首页突出当前推荐的一步，完整安排和其他工具可以按需打开。资料管理、学习记录、设置及独立阅读允许正常滚动；长题和长答案保留完整内容。

## 下载与启动

完整本机启动入口当前面向 **Windows**。先安装 **Node.js 24.13.1 或更新的 24 系列版本**，再在 PowerShell 中执行：

```powershell
git clone https://github.com/neutrino843/Cat-Thinking.git
cd Cat-Thinking
npm.cmd ci
```

如果通过 ZIP 下载，请先「全部解压」，进入包含 `package.json` 的文件夹后执行 `npm.cmd ci`。使用 `npm.cmd` 可以避开 PowerShell 对 `npm.ps1` 的执行限制。

### 只体验页面和本地学习

```powershell
npm.cmd run dev
```

打开 **http://127.0.0.1:5173/**。可以导入资料、完成原文入门题、阅读和编辑导图，以及继续当前浏览器已有的课程练习。这个入口不启动数据库或 AI 后台，因此不能生成新的 AI 内容。

端口 5173 被占用时会提示并停止。请先停止自己之前启动的页面服务，避免重复打开。

### 启动完整本机应用

```powershell
npm.cmd run start:local
```

也可以双击仓库内的 [启动猫思之.cmd](./启动猫思之.cmd)。首次启动会按需下载并准备本机 PostgreSQL、初始化数据库，再启动后台和页面；需要联网并等待。无需购买云数据库，也无需复制原开发者的数据库或密钥。

完整入口会选择可用端口并尝试打开浏览器，**请使用启动窗口显示的网址**。保留启动窗口，结束时按 **Ctrl+C**。两种启动方式按需要选一种即可。

数据库及加密配置位于仓库文件夹旁的 `.cat-thinking-postgres`，不随源码分发。首次安装和跨电脑恢复尚未在全新 Windows 电脑上完成验收。其他系统的完整后台配置见 [后台说明](./services/analysis-service/README.md)。

## 第一次使用：从导入到第一题

不需要先阅读开发文档，也不需要先配置模型：

1. 在首页选择 **开始使用 · 伊希斯带我完成第一题**，导入一份讲义或笔记；也可以先体验示例课程。
2. 检查导入预览，确认后保存。首次引导会进入原文入门题；普通导入完成后，也可以选择查看导图、直接学习或回到首页。
3. 先尝试回答。需要帮助时，点伊希斯选择 **看相关段落**，或使用题目旁的帮助入口。
4. 想读完整资料时，点伊希斯选择 **进入独立阅读**；也可以输入“我想进入独立阅读”，再点击气泡提供的入口。返回后继续刚才的答案。
5. 提交并对照原文，然后选择 **去课程继续学习**。已有正式学习内容可以接着使用；没有题库时，可以先阅读原文、写自己的理解，再按需准备更多内容。

入门题用于熟悉流程，**不计入正式题库，也不代表已经掌握知识**。资料过短、没有可用正文或原文发生变化时，需要先检查资料。

## 按自己的节奏学习

- **从哪里开始**：首页支持自动推荐、先选课程、到期复习优先。
- **这轮怎么学**：可选择逐步学习或直接练习；已有保存轮次会保留原步骤与进度。
- **今天学多少**：通过「今天的分量」调整分钟数和最多题数，这是安排预算，不是倒计时。
- **怎样陪伴**：在「更多 → 学习偏好」调整伊希斯的提示方式、左右位置、轻微动作与学习纪念展示。安静模式仍保留小猫，点击才展开对话。
- **什么时候复习**：查看实际作答后的建议，再决定是否采用或自己选日期。采用一次建议不会开启长期自动复习，已有手动日期优先保留。

复习目前使用 1、3、7、14 天的固定间隔规则，结合回答、自评和是否使用帮助决定建议。学习纪念来自真实记录，示例课程不计入个人成就；练习表现、自评和纪念都不等于掌握率。

**伊希斯目前使用预设内容和规则识别，尚未接入自由 AI 对话。** 她可以说明当前步骤、提供原文入口和操作帮助；遇到不支持的问题会说明能力范围。

## 按需使用 AI

本地入门练习和 AI 生成是两个入口。需要整理更多内容时：

1. 使用完整本机启动方式，在 **更多 → AI 设置** 中选择服务商，填写自己的 API 密钥和模型；本机模型需先在相应服务中准备好。
2. 点击 **保存并连接**，核对连接状态。服务商不提供模型列表时，可以手动填写模型名称。
3. 在 **AI 分析** 中选择原文范围和需要的结果，确认后明确点击生成。
4. 结果生成后先核对引用，再选择 **保存为学习资料**。在课程中核对知识点、题目与学习范围后，接入正式学习、补学和复习。

摘要、大纲和入门题不会自动变成完整正式题库。已有生成任务优先恢复查看，不会因刷新、查看结果或进入阅读自动重发生成请求。

生成会将所选原文发送给连接的服务商，可能产生费用；失败或格式修复也可能产生用量，实际费用以服务商账单为准。API 密钥保存在本机后台的加密存储中，不写入浏览器本地存储。模型兼容范围与配置细节见 [模型兼容说明](./docs/PROVIDER_COMPATIBILITY.md)。

## 保存与备份

页面中的资料、课程和学习记录保存在当前浏览器，**尚无云同步**。换浏览器、换应用网址或清理浏览器数据后，原记录可能不可见；不要把浏览器保存当成长期备份。

| 备份方式 | 适用范围 |
| --- | --- |
| **更多 → 资料与备份**，导出 `.mszcourse` | 课程关联文档、附件、归档原文、学习记录和复习安排；可设置 8 至 200 字符的密码 |
| 课程包恢复 | 先检查再恢复为新课程；包内学习偏好只有在明确勾选后才应用，不包含 API 密钥或后台任务 |
| 导图工具中的 JSON / `.msz` | 单篇文档及编辑内容；不替代课程作答和后台数据备份，大附件需要另行保留 |
| `npm.cmd run db:backup` | 本机后台数据库；需要与对应的加密配置配套保管，不能当作跨电脑一键迁移 |

课程包只包含归属该课程的内容，未加入课程的文档需要另行备份。SVG、PNG、PDF 导出用于展示，不能替代完整可编辑备份。

## 当前边界

- 导入单文件上限为 **25 MB**，提取文本上限为 **200 万字符**。扫描版 PDF 和图片暂不支持文字识别；PPTX 不提取演讲者备注，旧版 `.ppt` / `.pptm` 需先转换为 `.pptx`。
- 正式练习需要已保存且核对过的学习内容。AI 结果和客观题参考答案仍需对照原文检查。
- 目前的复习建议不提供个性化记忆预测；学习效果仍需真人体验和长期验证。
- 完整本机启动脚本面向 Windows；离线安装包仍为原型，见 [安装包说明](./scripts/desktop/README.md)。

## 遇到启动问题

先双击 [诊断启动.cmd](./诊断启动.cmd)，或在仓库根目录运行：

```powershell
node scripts/startup-preflight.mjs
```

检查只核对 Node.js、项目文件和依赖，不安装数据库或调用 AI。依赖缺失时执行 `npm.cmd ci`；Node.js 不符合要求时安装上述 24 系列版本并重新打开终端。中文目录可以直接使用，ZIP 文件需要完整解压。

仅运行 `npm.cmd run dev` 时，AI 后台不可用属于预期行为。完整启动失败时保留终端最后的报错，先核对依赖、下载和连接状态，不要删除旧数据库或密钥来尝试修复。

## 继续开发

页面使用 React、TypeScript 和 Vite；本地资料与学习数据使用 IndexedDB；AI 后台使用 Node.js 与 PostgreSQL。源码、共享数据约定、测试代码和启动工具都在同一仓库中。

| 命令 | 用途 |
| --- | --- |
| `npm.cmd run dev` | 启动页面与本地学习功能 |
| `npm.cmd run start:local` | 启动完整本机应用 |
| `npm.cmd run build` | 检查类型并打包页面 |
| `npm.cmd run build:service` | 编译 AI 后台 |
| `npm.cmd run lint:ci` | 代码规范检查 |
| `npm.cmd test -- --no-file-parallelism` | 运行自动测试 |
| `npm.cmd run e2e:install` / `npm.cmd run e2e` | 安装测试浏览器 / 运行页面测试 |

`npm.cmd run preview` 只预览打包后的页面，不能代替完整后台或生产部署。真实模型与数据库检查需要单独配置相应环境。

详细说明：[开发说明](./DEVELOPMENT.md) · [后台说明](./services/analysis-service/README.md) · [共享数据约定](./packages/analysis-contracts/README.md)。

仓库保留源码、测试、固定测试素材和产品图片。审计报告、测试结果、运行截图、设计方案及演示材料仅在本地保留；个人密钥、数据库和用户备份不随代码提交。
