## 6 历史结果必须怎样引用

### 6.1 自动验证的范围

V3 报告记载 1621 项单元通过、48 跳过，以及最终 184 项 Chromium 浏览器通过。2026-10-19 保底实施报告记载 123 项单元专项、47 项浏览器专项、12 项演练和 10 项布局检查。上述范围有重叠，不能相加成为全产品独立验证数。本轮只阅读报告，未重新执行或逐个核验所有原始 JSON。

保底演练的题目为预置内容，报告明确 AI 生成 POST 为零。它支持当时“已有归档内容的学习、恢复路径可用”的结论，不支持“真实模型生成五类产物及质量已全面通过”。

### 6.2 移动云和长任务结论的时间线

1. 早期报告记录短问答成功，但整篇样例在依据阶段未完整结束或响应丢失。
2. 接入报告尾部又记录思考参数探针与适配修复，以及后续受限样例完成了若干调用但遇到验收框架总时限。该记录不能丢失，也不等于五类内容全部通过。
3. 五任务优化计划追加的数据库取证记录一个摘要加测验任务后台已经成功，约 51 秒、4 次调用；页面误报与查询限流相关。因此不能笼统写“长任务从来没成功”。
4. 合理结论是：存在部分真实成功与具体失败证据；完整五类产物、所有课程材料和 V4 新提示质量仍需各自验收。不能将局部成功推广到全部，也不能忽略后续成功只引用最早失败。

### 6.3 性能推断的使用限制

体验优化计划提出减少一次 repair 后可能从约 51 秒到 35—36 秒，这是特定历史场景的推算，不是本轮实测提速。报告中“已无安全工程压缩空间”同样是当时管线分析的结论，不能成为 V4 的普遍限制：V4 仍可通过只生成所需节点、复用已核对结果和避免重复上下文来减少无用任务。具体收益必须在相同模型和预算下测量，不写保证提升百分比。

## 7 旧需求的继承与变更

| 旧需求 | V4 决定 | 处理理由及追踪 |
| --- | --- | --- |
| 首次体验做一道题 | 修改默认体验，旧入口兼容 | 先完成一个节点的理解与保存；CT4-NODE-01 |
| 学习界面题目优先 | 节点优先，正式练习内部仍按题处理 | 避免无题不能学；CT4-LEG-01 |
| 学习准备默认 5 题 | 仅保留在按需练习路径 | 章节骨架是 V4 默认准备内容；CT4-MAP-01 |
| 导图不进入首条路径 | 知识骨架进入主线，图形视图不是强制 | 可用大纲或节点列表完成，不必操作巨型画布 |
| 三条学习主线并列 | 入口收敛，能力兼容 | 保留旧会话恢复，不强迁移历史 |
| 答错再提示 | 推导卡住即可提示，题目纠错仍保留 | 不对自由推导预先自动判错；CT4-HINT-01 |
| 每级提示与自我解释 | 继承并补无题轮次隔离 | 层级以本次问题为单位，防串稿；CT4-HINT-02 |
| 本机模型捆绑、4B/8B 与完整离线 | 后续可选方向 | 首版用户自配模型；不删除已有配置和模型 |
| 单一移动云型号优先 | 作为已有服务适配保留 | V4 的核心不依赖某历史型号永久有效 |
| 故事、RPG、轻成长同期 | 实用引导优先，游戏层后移 | 配置教材和节点操作帮助直接支持主流程 |
| 甘特作为核心体验 | 兼容保留工具入口 | 不把知识前置关系转成日期排程依赖 |
| 草稿归属、资格、未知辅助问题 | 继续列为可信性要求 | 转向节点不能掩盖旧练习风险 |
| 48/72 小时参赛窗口 | 不作为 V4 全量交期 | 新数据契约和订阅需求超过原保底范围 |
| 真人观察为旧计划完成定义 | 不作为本次报告前置 | 工程和内容验收仍保留，宣传学习成效不能虚构 |

## 9 产品策略子代理复核与编制者处理

本节依据本聊天产品策略子代理的只读复核意见整理；不是实际运行测试审计。下列问题由编制者回答并映射到文稿，不再询问用户。

| 审计问题 | 回答与落实 |
| --- | --- |
| 无题节点是否能学习 | 能；CT4-NODE-01 明确无题、无模型的读写路径 |
| 跨章节是否真的首版交付 | 是；CT4-LINK-01 及 M1 均强制纳入，自动推荐后移 |
| 是否必须显示全课程大图 | 不必；关系列表和跨章往返可先完成，图形只是视图 |

| 教材是否默认整本发送 | 否；CT4-CTX-01 展示本次片段和预算，不足依据明示 |
| 引用是否等于答案正确 | 否；CT4-SRC-02 区分定位有效与推理正确 |
| 提示是否自动越级 | 不自动；CT4-HINT-01 逐次主动查看，完整解释明确标识 |

| 订阅到期是否锁个人框架 | 不锁；保留手工编辑、访问和导出，自动工作流权益另管 |
