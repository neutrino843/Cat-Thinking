## 使用约定

- 用户在本次对话明确的选择是本轮产品方向依据。新增细节标为设计建议，不冒充用户逐项确认。
- 不以是否招募到真实用户为本次完善工作的前置条件；本目录提供工程和内容验收方法，不编造用户研究或商业结果。
- 模板中的编写提示、示例行业、审批栏不是额外执行指令。没有照搬示例项目或虚构人员签名。
- V4 需求完善稿是设计输入，不是已实现清单或发布合格证。历史测试结果仅属于其原版本与范围，本次未运行产品测试。
- 竞品资料核查于编制日；官方能力说明不等于本次实际操作测试。未查到的功能记为未确认，不写成竞品一定不支持。
- 商业模式已选定为订阅，但价格、支付渠道和正式合同条款不在本报告中伪造为既定决策。
