# 猫思之 Windows 离线安装包

此包包含构建后的应用、Node.js 24 运行时、后端生产依赖和 PostgreSQL 18.6 原生运行时。目标电脑无需预先安装 Node.js、npm 或 PostgreSQL。使用已有 Chrome/Edge/默认浏览器；它不是内嵌浏览器桌面壳。

解压整个目录，双击 `Install.cmd`。安装仅写当前用户的程序和数据目录，不修改全局 PATH、注册系统服务，也不启动模型连接。程序按版本保存，数据默认保存在 `%LOCALAPPDATA%\CatThinkingData`。桌面/开始菜单的 CatThinking 启动应用，Stop CatThinking 正常停止后台与数据库。关闭浏览器窗口不会停止后台。

应用地址固定为 `http://127.0.0.1:53013`，后台为 53014，数据库为 55435。端口占用会停止启动，不会自动换地址或关闭其他软件，因此浏览器里的课程库不会因端口回退而变成另一份数据库。

升级前使用自己的停止快捷方式。升级新增版本目录，保留数据库、加密密钥和原版本；第一次启动会暂停已有 AI 执行授权，用户在应用中重新确认连接。数据库主版本升级必须另行迁移，不通过替换二进制直接升级已有集群。

受保护备份入口先要求用户导出并选择所有需要保存的 `.mszcourse` 文件，确认数量，然后将这些文件与数据库及必要解密配置一起以密码保护。密码至少 10 个字符，不写入命令行、环境变量或备份明文。此入口不会自动读取浏览器数据；课程包以外的未组织文档仍需单独导出。课程文件可以已有独立密码，本备份不保存这些密码。

当前受保护备份的总内容上限为 512 MB。超过上限会停止并保留现有数据，不静默省略附件；更大数据集需后续实现流式备份。

恢复只接受尚不存在的隔离目录，校验全部文件后恢复到新的 PostgreSQL 集群；现有安装不会被覆盖。恢复端口默认 53113/53114/55436。密钥保持原值、AI 执行保持暂停，课程包还需通过应用恢复中心明确导入。数据库与浏览器课程导出发生在不同时间，不宣传为同时快照。

运行安装目录的 `uninstall.ps1` 默认仅删除本应用程序文件并保留数据；`-DeleteData` 才明确删除属于该安装的全部数据。它只请求自己的后台停止，不按进程名称全局终止 Node 或 PostgreSQL。

安装包包含 SHA-256 清单，校验用于发现损坏和混入文件，当前没有代码签名。仅在已知来源获得整个安装目录后运行。制作环境和隔离新数据目录验证与“干净 Windows 虚拟机验证”不同；后者尚未完成，仍需检查系统运行库、首次安装、升级、中文用户目录和跨盘恢复。

构建命令：`npm run desktop:package`。无需联网下载运行时；构建器读取现有 `dist`、服务 `dist`、生产依赖及已安装的原生 PostgreSQL，只包装程序，不复制开发机的数据库、密钥、日志、资料或配置。输出位于工作区上级 `output/desktop`。

## V3 捆绑模型引擎

V3 开发标识为 `3.0.0-dev.1`。3.x 包必须通过 `--ollama-root` 提供经过核验的完整 Windows 独立引擎目录，不能只复制 `ollama.exe`。目录必须带 `LICENSE` 及适用的 GPU 运行库；构建会记录引擎版本，并把文件加入 payload 摘要清单。

```powershell
npm.cmd run desktop:package -- 3.0.0-dev.1 --ollama-root "D:\发行依赖\ollama-windows-amd64"
```

发布目录应来自官方发行包，并由项目组核验下载来源和原始摘要。payload 摘要证明打包后完整性，不代替供应商来源或签名验证。本次仅实现打包支持，尚未制作捆绑引擎的二进制发行包、未做干净 Windows 安装验收。

应用优先使用 `runtime/ollama/ollama.exe`。模型权重由用户在 AI 设置中选择目录并主动下载，提供较小/较强两档；模型权重不包含在课程包或此构建的默认 payload 中。更换目录不自动迁移旧模型，外部运行中的引擎不由本软件强制终止。详情见 `docs/v3/软件需求规格说明书_V3.md`。
